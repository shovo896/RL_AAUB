# IEEE conference paper package

This folder is ready to upload to Overleaf as a new project or merge into an existing one.

- Compiler: pdfLaTeX
- Main file: `main.tex`
- Bibliography: `references.bib` (exactly 20 research papers)
- Document class: `IEEEtran` with the `conference` option

Before submission, replace the anonymous author block in `main.tex` with the real author names, affiliations, and email addresses. The results and limitations are taken directly from `lstm+bellman_eqn.ipynb`; no unsupported 10x MAE claim is made. The recorded evidence supports 10.66x lower MSE and 3.73x lower MAE at the MSE-selected checkpoint.
